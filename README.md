# SlidCard

SlidCard is a non-commercial educational project created for learning, coursework, and experimentation with web development, game interfaces, local data storage, and simple online transaction systems.

## Non-commercial use

This version of SlidCard is intended only as:
- an educational project;
- a coursework/demo project;
- a personal development project;
- a prototype for learning web technologies.

The in-game currency has no real-world monetary value and cannot be exchanged for real money.

No real-money purchases, withdrawals, gambling, or financial services are provided by this project.

## Technology

The project is built with:
- HTML
- CSS
- JavaScript
- Google Apps Script
- Google Sheets
- GitHub Pages

## Purpose

The main purpose of SlidCard is to practice and demonstrate:
- responsive web design;
- game UI development;
- inventory systems;
- card pack mechanics;
- virtual markets;
- transaction logic;
- local account data and file-based account export/import.
